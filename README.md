# Consumer Complaint Classification NLP Project

An NLP-based system that automatically classifies consumer complaints into financial service categories using deep learning and transformer models.

## Project Overview

This project builds an end-to-end Natural Language Processing pipeline for classifying customer complaints. It includes text preprocessing, tokenization, sequence padding, model training, evaluation, and deployment using Streamlit.

## Models Used

- SimpleRNN
- LSTM
- GRU
- Transformer-based model (Hugging Face)

## Features

- Text cleaning and preprocessing
- Tokenization and padding
- Multi-class complaint classification
- Model evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - Confusion Matrix
- Interactive Streamlit web application

## Complaint Categories

The model predicts categories such as:

- Credit Reporting
- Debt Collection
- Mortgages and Loans
- Credit Card
- Retail Banking
